    GC쿼드 연결하기 (처음 한 번만)

    1. FSX 2020에서 설정 → General Settings → On-Screen Data → "Write Shots CSV"를 켜세요.
    2. 아래 연결 도우미 받기를 눌러 받은 파일 시몬골프_연결도우미.bat을 바탕화면에 두고 더블클릭하세요. 검은 창이 뜨면 그대로 켜두세요. (FSX가 저장하는 샷 파일을 '문서\SimonFitting' 폴더로 계속 복사해줘요)
    3. 공을 한 번 치세요. 그다음 샷 파일 선택을 누르고 문서 → SimonFitting → LastShot.csv를 고르세요.
    4. 크롬이 "파일 보기 허용"을 물으면 허용(가능하면 "방문할 때마다 허용")을 누르세요.

    Shots.csv(지난 세션 전체 기록)가 있으면 이 창에 끌어다 놓아도 한 번에 불러와요.
