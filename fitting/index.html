  3. 공을 치면 여기에 바로 나오고, 정한 횟수를 다 치면 다음 클럽을 알려줘요

    피팅 소견 (근거 포함 · 손님 화면엔 안 보여요)

      자세한 비교 (미스샷 제외 평균 · 초록 = 가장 좋은 값)

      샷 기록 (빨간 '미스'는 자동으로 평균에서 빠져요 · 다른 클럽으로 옮길 수 있어요)

      단축키: 1~6 클럽 고르기 · Shift+1~6 마지막 샷을 그 클럽으로 옮기기 · Delete 마지막 샷 빼기/되살리기 · D 손님↔피터 화면 · F 전체화면

      GC쿼드 연결 (처음 한 번만)

      1. ① FSX에서 샷 파일 켜기

        FSX 2020 설정 → General Settings → On-Screen Data 에서 Write Shots CSV(한글 화면이면 'CSV'가 들어간 항목)를 켜세요.

      2. ② 연결 도우미 켜기

        FSX가 만든 샷 파일을 C:\SimonFitting 폴더로 1초마다 복사해주는 작은 프로그램이에요. 둘 중 편한 것 하나만 하세요.

        방법 A (추천) → 받은 파일을 더블클릭하세요.
        크롬이 '위험할 수 있는 파일'이라고 하면 유지를, 파란 'Windows의 PC 보호' 창이 뜨면 추가 정보 → 실행을 누르세요. 검은 창은 켜둔 채 최소화하면 돼요. 처음 실행할 때 "PC 켤 때 자동 실행?"을 물으면 Y를 누르면 다음부턴 신경 안 써도 돼요.

        방법 B 파일 없이: 윈도우키 + R → 아래 줄 붙여넣기(Ctrl+V) → Enter

      3. ③ 폴더 연결

        아래 버튼을 누르면 폴더 고르는 창이 떠요. 창 위쪽 주소칸을 클릭 → Ctrl+V → Enter (C:\SimonFitting 이 복사돼 있어요) → 폴더 선택. 크롬이 물으면 '방문할 때마다 허용'을 고르세요.

      4. ④ 공 한 번 치기

        연결되면 친 공이 바로 화면에 나와요.

      바탕화면 아이콘 만들기 · 연결 없이 연습 · 파일 직접 넣기
      앱으로 설치하면 크롬 허용을 다시 안 물어요.
      Shots.csv 파일을 이 화면에 끌어다 놓아도 불러와요.

      오른쪽 서브 화면에 띄우기

      버튼이 안 될 때 (손으로 하기)
      1. 윈도우키 + P → 확장을 고르세요 (빔프로젝터와 서브 화면이 서로 다른 화면이 돼요).
      2. 이 크롬 창을 클릭하고 윈도우키 + Shift + → 를 누르면 오른쪽 화면으로 넘어가요. (마우스로 끌어도 돼요)
      3. F11을 누르면 전체화면이 돼요. 다시 누르면 원래대로.
      4. FSX가 서브 화면에 자기 클럽 데이터를 띄우고 있으면, 그 위에 이 창을 덮으면 돼요 (FSX 설정에서 서브 화면 표시를 꺼도 돼요).
